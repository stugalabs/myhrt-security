# Security Policy

## Reporting a vulnerability

If you find a security or privacy issue in this code (or in the MyHRT app),
please report it **privately** so it can be fixed before it's disclosed:

**privacy@myhrt.health**

Please do not open a public GitHub issue for a suspected vulnerability.

Useful things to include: what the issue is, how to reproduce it, and the
impact you think it has. Proof-of-concept code is welcome but not required.

## Scope

This repository is the at-rest encryption and secure-storage layer of MyHRT.
Reports about the wider app (the parts not published here) are equally welcome
at the same address.

## What to expect

MyHRT is a small, independent project, so there is no formal bug-bounty
programme. Reports are read and acted on as quickly as one maintainer can
manage, and anyone who reports a genuine issue will be credited (with their
permission) once it's resolved.

## Please don't

- Test against other people's data or accounts (there are none, the app is
  local-only, but the principle stands).
- Publicly disclose an unfixed issue.
