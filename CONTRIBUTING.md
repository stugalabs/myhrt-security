# Contributing

Thanks for taking an interest in MyHRT. This repository is the security-critical
source of the app, copied here verbatim so anyone can read and check how MyHRT
protects health data on the device.

## Pull requests

This repo is a read-only mirror. The files are copied byte-for-byte from the app,
and that exact match is the whole point: it is what lets you verify the published
code against the shipped app. Merging a change here would break that, so pull
requests are not accepted, and code only ever flows in from the app itself.

That does not mean there is nothing to do. The most useful contributions to a
repository like this are not code, and they are genuinely welcome.

## Ways to help

- **Read and verify the code.** This is what the repo is for. If you spot
  something that looks wrong, or a place where the published code does not seem to
  match what the app does, please say so. That kind of scrutiny is the point.
- **Report a security or privacy issue.** Please do this privately, following
  [SECURITY.md](SECURITY.md) (email privacy@myhrt.health, not a public issue), so
  it can be fixed before it is disclosed.
- **Report a bug in the app.** Open an issue here, or email hello@myhrt.health.
  What you saw, what you expected, and how to reproduce it all help.
- **Suggest a feature or an improvement.** Same channels. No idea is too small; a
  lot of the app has grown from user suggestions.
- **Share it.** Tell someone who might find MyHRT useful. Word of mouth is how a
  local-first, no-accounts app reaches the people it is for.
- **Support the project.** Entirely optional. There is a Sponsor button on this
  repo (Ko-fi) if you would like to chip in. The app stays free either way.

MyHRT is a small, independent project run by one maintainer, so replies may not be
instant, but every message is read. Thank you for helping make it better and more
trustworthy.
